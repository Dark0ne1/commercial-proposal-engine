# Отчёт о реализации и выполненных проверках

19 октября 2026 года. Локальная среда: Windows, Python 3.13.7, Node.js 24.13.0, Chrome, LibreOffice.

## Реализовано

Полный цикл заявки: текст или XLSX/DOCX/PDF → извлечение позиций → агентные инструменты → уточнения → черновик КП → правка менеджером → подтверждение → DOCX и PDF → история и журнал.

- FastAPI, Pydantic 2, SQLAlchemy 2, Alembic; Next.js, TypeScript, Tailwind CSS.
- Шесть типизированных инструментов: search_catalog, get_customer, get_price, check_availability, calculate_quote, create_quote_draft.
- Настоящий цикл tool calling, OpenAI-compatible адаптер и явно обозначенный mock-провайдер без API-ключа. Журнал вызовов, ошибок, длительности и токенов.
- Очередь RQ, повтор задач, идемпотентность, защита от устаревшего worker и восстановления после сбоя.
- Серверные расчёты Decimal, правила скидок и НДС, неизменяемые снимки версий КП, подтверждение менеджером.
- Извлечение документов с ограничениями размера и структуры, проверка связи извлечённых фактов с исходной заявкой.
- Реальный DOCX и PDF через LibreOffice, включая многостраничные таблицы.
- Синтетические данные: 50 клиентов, 150 товаров, 40 заявок, 20 исторических КП. Фиксированный seed и повторяемое заполнение.
- Подготовлены Dockerfile, Compose, health checks, volumes, автоматические миграции и GitHub Actions.

## Выполненные проверки

- **77 backend-тестов прошли.** Проверены деньги, скидки, НДС, каталог, неоднозначности, история, API, безопасность документов, идемпотентность, повтор задач и защита worker от потери владения задачей.
- **16 golden-сценариев агента:** найденные позиции, неполные и неоднозначные заявки, уточнения, проверка исходных фактов и вызовов инструментов.
- Адаптер LLM проверен через локальный HTTP transport: tool calls, структурированный ответ, usage, ошибки 401/429/500 и тайм-аут. Внешний платный API не вызывался.
- **5 проверок Playwright прошли:** ручной цикл с правкой и подтверждением, ограничение тела запроса, XLSX → RQ → агент → скачивание документов, уточнение неоднозначной заявки и точное форматирование денежных сумм.
- Браузерные сценарии обращались к запущенным API и production UI. Для локальной очереди использован тестовый TCP Redis-эмулятор с настоящим RQ worker.
- Генерация DOCX/PDF выполнена через установленный LibreOffice. Проверены кириллица, суммы, повтор конвертации и КП на 100 строк. Страницы PDF просмотрены визуально.
- Alembic на отдельной SQLite-базе: upgrade → check без расхождений → downgrade base → upgrade. Проверены повтор seed и reset.
- Ruff, TypeScript typecheck, production build Next.js, pip check. npm audit: **0 vulnerabilities**.
- Просмотрены desktop и mobile screenshots; таблица прокручивается внутри контейнера без общего горизонтального переполнения.

## Запуск

Скопировать `.env.example` в `.env`, задать собственные пароли и выполнить:

```sh
docker compose up -d --build
docker compose exec api python seed.py
```

Подробности: [DEPLOYMENT.md](DEPLOYMENT.md), API: [API.md](API.md), сценарии: [DEMO_SCENARIOS.md](DEMO_SCENARIOS.md).

Локальное демо: UI http://127.0.0.1:3000, API http://127.0.0.1:8000/docs.
Демоаккаунт: `manager@example.test`, пароль `demo-password-123`.
Данные вымышлены. Для собственного развёртывания задать другой `DEMO_PASSWORD`.
