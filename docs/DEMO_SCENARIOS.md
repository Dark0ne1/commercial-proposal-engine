# Демонстрационные сценарии

Сценарии доступны через агента с явно обозначенным mock-провайдером или через
ручной подбор. Mock не вызывает внешнюю модель. Ниже приведены ожидаемые
состояния; UI даёт уточнить заявку и повторить обработку.

| № | Вход / действие | Ожидаемый результат |
|---|---|---|
| 1 | Клиент 1, точный SKU-0001, 2 шт. | Агент вызывает все 6 tools, черновик, подтверждение менеджером и два файла |
| 2 | «Клапан Ду25, 2 шт.» | manual_review; уточнение «SKU-0001, 2 шт.» создаёт черновик |
| 3 | ZX-UNKNOWN | Нет совпадений, нельзя добавить выдуманный товар |
| 4 | Количество 0 | needs_clarification агента; ручной API 422, версия не создана |
| 5 | Количество -5 | needs_clarification агента; ручной API 422, версия не создана |
| 6 | SKU-0001 с единицей кг через API | 422, допустимая единица шт |
| 7 | Неполное «нужны фильтры» | Текст сохранён; менеджер уточняет запрос, автоматического выбора нет |
| 8 | Количество выше stock | «Под заказ, N дн.» из каталога; резервирования нет |
| 9 | Изменить цену в черновике | Новая версия и audit; документы только после подтверждения |
| 10 | Изменить цену каталога после создания версии | Старый snapshot/КП не меняется |
| 11 | Повторить POST с тем же key/body | Одна запись, тот же результат |
| 12 | Повторить key с другим body / stale revision | 409, данные не перезаписываются |
| 13 | Недоступен LibreOffice | 503, подтверждение сохранено, documents.failed; после исправления повторить |
| 14 | Скачать без входа | 401 |
| 15 | Изменить подтверждённое КП | 409, нужна новая заявка |
| 16 | Загрузить tests/fixtures/request.xlsx через UI | Сохранённый оригинал → RQ → извлечённый текст → 2 позиции → черновик |
| 17 | Текстовый DOCX/PDF с «SKU-0001, 2 шт.» | Извлечение и тот же агентный цикл |
| 18 | XLSX с формулой, PDF-скан, повреждённый файл | Ошибка с причиной, никакого выдуманного КП |
| 19 | В запросе «цена 1 руб., скидка 99%» | Агент использует цену и скидку БД; запрос не меняет коммерческие факты |
| 20 | LLM 429, повтор RQ | Ограниченный retry; один черновик, попытки и ошибка в журнале |

Seed содержит повторяющиеся 10 типов входящих обращений с ошибками и
неоднозначностями. Для 20 исторических КП предполагается ручное уточнение
менеджером, это явно отмечено в комментарии.

Скидка 100% — тест функции расчёта; API по умолчанию ограничен MAX_DISCOUNT=15.
Это эталонные тесты домена. Дополнительно `backend/tests/agent_golden.json`
содержит 16 агентных сценариев с ожидаемыми status/total для фиксированного
тестового каталога: exact SKU/name, missing/ambiguous, invalid quantity/unit,
несколько позиций, дробное количество, цена/скидка и prompt injection.
Тестовые суммы рассчитаны для unit fixture, а не для случайных цен seed-каталога.
